# Braininger

Ein selbstgebauter Sprach-Notizblock nach dem Vorbild des Plaud Note Pro: Android-App zum Aufnehmen, Windows-Programm zum Auswerten.

- **Handy (Android):** Widget mit „Gedanke“ und „Gespräch“, Aufnahme im Hintergrund, Upload in Google Drive.
- **Laptop (Windows):** Texterkennung lokal mit [faster-whisper](https://github.com/SYSTRAN/faster-whisper), Sprechertrennung mit [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx), Auswertung mit Claude Code.

Gebaut mit Claude Code. In diesem Projekt liegen nur Programmcode und Vorlagen, keine Aufnahmen, Texte oder persönlichen Daten.

## Stand
Stufe 1 im Aufbau.
